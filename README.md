# gurmanalexander.github.io

Личная страница Александра Гурмана: https://gurmanalexander.github.io/

- `index.html` — вёрстка и стили, без фреймворков и сборки.
- `data.js` — весь контент (проекты, опыт, стек) на русском и английском. Чтобы добавить проект, допишите объект в массив `PROJECTS`.
- `assets/` — фотографии и скриншоты.
